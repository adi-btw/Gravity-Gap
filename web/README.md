# Gravity Gap web app

Next.js 15 (App Router) + React 19 + TypeScript + Tailwind v4. Hand-rolled SVG charts (no Plotly). Phase-1 physics
runs in the browser (`lib/physics.ts`, a port of `engine/physics.py`); phase-2 pages read the FastAPI backend and fall
back to static artifacts when it is down.

## Install, develop, test

```bash
cd web
npm install
npm run dev        # copies artifacts (predev), then http://localhost:3000
npm test           # vitest
npm run lint       # eslint (next/core-web-vitals + next/typescript)
npm run build      # copies artifacts (prebuild), then a production build
npm start          # serve the production build
```

Run the API next to it from the repo root: `python -m uvicorn api.main:app --port 8000`.

## Pages

| Route | Feature | Data | Offline behaviour |
|---|---|---|---|
| `/` | landing, quick read, links to bounds/regime/spectrum | client physics | full |
| `/explore` | F1 gravity spectrum map, ranked evidence with editable weights | `/catalog`, `POST /rank` | spectrum from `catalog.json`; ranking shows catalog order with "offline: ranking needs API" (never ranked client-side) |
| `/regime` | F2 + F3 | client physics | full |
| `/bounds` | F4 bounds panel (`?metric=M1..M5`), Explain via `POST /ask` | `/metrics`, `POST /bounds` | the six presets from `bounds/{preset}_{metric}.json`; custom habitats say "live API needed" |
| `/investigations/[id]` | F7 card, "Ask about this" | catalog (pre-rendered at build via `generateStaticParams`) | full |
| `/ledger` | F5 ledger, in-browser SHA-256 re-verification | `GET /ledger` | from `ledger/predictions.jsonl` |
| `/planner` | F6 ranked test plan + design implications | `/planner` | from `planner.json` |
| `/data` | F8 filterable test table, CSV/JSON export | `/data/tests`, `/data/export` | "live API needed" |
| `/about` | method, limitations, every DOI in the catalog | bundled catalog | full |

The **Ask** drawer (header button) posts to `/ask`. Offline it answers only the pre-generated questions in
`ai_cache.json` (exact or near match) and otherwise says the live API is needed. Every page shows a "live API" or
"offline data" chip.

## Offline artifacts

`scripts/copy-artifacts.mjs` (run by `predev`/`prebuild`, or `npm run copy-artifacts`) copies `../artifacts/**/*.json|md`
and `../ledger/predictions.jsonl` into `public/artifacts/` (git-ignored). Missing sources are skipped with a warning.
`lib/api.ts` tries the API with a 2.5 s timeout and falls back on network errors, timeouts, 404 and 5xx; 4xx input
errors (for example 422) are shown, not hidden by a fallback.

## Ledger hash

`lib/ledger.ts` mirrors `engine/ledger.py`: SHA-256 of `json.dumps(record_without_sha256, sort_keys=True,
separators=(",", ":"), ensure_ascii=False)`. Records are parsed with a lexeme-preserving JSON parser so Python number
spellings (`10.0`, `1e-05`) hash exactly; `JSON.parse` would lose them. The test compares against a hash generated by
`engine/ledger.py` and re-verifies the real ledger file.

## Layout

- `app/` pages; `components/` panels, `components/charts/` SVG charts (BandChart, TornadoChart, GravitySpectrum,
  RegimeFractionsBar, RegimeMap, GStarMap, GapHero), `components/ui/States.tsx` loading/error/empty/source chips.
- `lib/api.ts` data layer, `lib/ledger.ts` hash verification, `lib/markdown.ts` safe Markdown parser (AST rendered as
  React elements; raw HTML stays text, only http(s)/mailto/relative links, `[PSI-69]`/`[rec:…]`/`[doi:…]`/`[eng:…]`
  become citation chips), `lib/catalog.ts` card helpers.
- `components/HabitatBar.tsx` (F0): habitat in the URL (`?g=&p=&o2=&u=&L=`), so every link is shareable.
- Tests (`lib/*.test.ts`): physics parity with `../tests/fixtures/physics_reference.json`, presets parity, data-layer
  fallback, safe Markdown, ledger hash, catalog helpers.
